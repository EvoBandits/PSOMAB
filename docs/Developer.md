# Developer Documentation

## When to use Eigen and when to use std::vector
Use Eigen when you need to do linear algebra. Use std::vector when you need to do dynamic memory allocation.

## Submodules
How to include a certain library as subpackage:
1. Navigate to folder (here: `third_part` )
2. Execute the following command using the terminal:
3. `git submodule add -b 3.4 https://gitlab.com/libeigen/eigen` (-b allows to specify a certain branch)

### Use submodules in your project
1. clone project
2. `git submodule update --init --recursive` (this will clone all submodules)

## Commit messages
Commit messages should be written in the imperative mood, e.g. "Fix bug" and not "Fixed bug" or "Fixes bug." This convention matches up with commit messages generated by commands like git merge and git revert.
