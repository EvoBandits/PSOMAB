## Submodules
How to include a certain library as subpackage:
1. Navigate to folder (here: `third_part` )
2. Execute the following command using the terminal:
3. `git submodule add -b 3.4 https://gitlab.com/libeigen/eigen` (-b allows to specify a certain branch)
